# Чтение DWG в браузере

Превращает чертёж AutoCAD в треугольники: разбирает файл, раскрывает вставки
блоков и режет тела ACIS. Собирается в `.wasm` и подключается во фронтенде
ленивым чанком — рядом с загрузчиками FBX и OBJ.

## Почему это написано, а не взято готовым

DWG закрыт, и объём в нём хранится телами ACIS — те самые данные, за доступ к
которым Open Design Alliance берёт около $38 000 в год. Разведка на реальных
файлах показала 64 тела ACIS и ноль готовых 3D-граней: без разбора ACIS от
чертежей не остаётся ничего.

Бесплатный путь нашёлся: [acadrust](https://github.com/hakanaktt/acadrust)
(MPL-2.0) читает DWG R13–R2018 вместе с ACIS и отдаёт топологию B-rep. Лицензия
разрешительная — открывать надо только правки в файлах самой библиотеки. Не
хватает только шага «границы → треугольники», он и написан здесь.

## Сборка

```bash
cargo build --release
```

Цель `wasm32-unknown-unknown` прописана в `.cargo/config.toml`, отдельно
указывать не нужно. Нативной сборки у пакета нет и не предполагается: в
зависимостях есть `getrandom`, которому под Windows нужен полный mingw, а под
wasm он не нужен вовсе.

Результат: `target/wasm32-unknown-unknown/release/dwg_wasm.wasm`, около 1,2 МБ.

## Проверка

```bash
node run.mjs чертёж.dwg                 # разбор в треугольники + сводка
node run.mjs чертёж.dwg --probe         # состав чертежа и поверхностей
node run.mjs чертёж.dwg --obj out.obj   # выгрузка, чтобы посмотреть глазами
```

`run.mjs` дёргает тот же модуль и тот же интерфейс, что пойдёт в браузер, —
проверять можно не поднимая сайт.

### Как понять, что разбор верен

`--probe` сравнивает габарит разобранной геометрии с тем, что записал в
заголовок файла сам AutoCAD, и отдельно считает тела, вылезшие за эти границы.
Совпадение габаритов и ноль вылезших — признак, что вставки блоков и
размещения ACIS применены правильно. Это оказалось единственным надёжным
способом поймать ошибки в матрицах: геометрия при них не ломается, а просто
уезжает не туда, и по числу треугольников этого не видно.

## Устройство

| Файл | Что делает |
|---|---|
| `lib.rs` | интерфейс наружу: голый C-ABI, без wasm-bindgen |
| `blocks.rs` | обход чертежа с раскрытием вставок блоков |
| `xform.rs` | матрицы: вставки, системы координат объекта, размещения ACIS |
| `tess.rs` | обход B-rep и разрез поверхностей на треугольники |
| `tri.rs` | триангуляция многоугольника с отверстиями |
| `probe.rs` | разведка: состав чертежа и сверка положения |
| `rng.rs` | источник случайности для хеш-таблиц под wasm |

## Что пока не покрыто

- **Сплайновые рёбра** идут хордой между вершинами: выборка таких кривых
  появилась в acadrust только после версии 0.4.1. Около 2% рёбер, заметно
  лишь на скруглениях.
- **Сплайновые поверхности** приближаются плоскостью по контуру. В проверенных
  чертежах это 25 граней из 4773.
- **Цвета и слои** не переносятся — вся геометрия идёт одной сеткой.
