# Разведка DWG

Отвечает на вопрос, от которого зависит вся поддержка DWG в VOVPLAN:
**можно ли вытащить из ваших файлов 3D-геометрию бесплатным LibreDWG, или там
ACIS-тела, для которых нужен платный ODA SDK.**

## Зачем

В DWG объём хранится по-разному:

| Что внутри | LibreDWG (бесплатно) | Итог |
|---|---|---|
| 3D-грани и сетки (`3DFACE`, `MESH`, `POLYLINE_MESH`) | ✅ читает | Готовая 3D-геометрия |
| 3D-тела ACIS (`3DSOLID`, `REGION`, `BODY`) | ❌ данные зашифрованы | Нужен ODA SDK |
| Плоский чертёж (линии, полилинии) | ✅ читает | 3D-модели нет, но линии можно наложить на рельеф |

AutoCAD чаще всего пишет объём именно как ACIS — поэтому проверять надо на
реальных файлах, а не гадать.

## Запуск

```bash
cd tools/dwg-inspect
npm install
node inspect.mjs "C:\путь\к\папке\с\чертежами"
```

Можно указать и отдельные файлы. Скрипт ничего не изменяет и никуда не
отправляет — читает локально.

## Что покажет

По каждому файлу — вердикт и состав объектов, в конце сводка и рекомендация:
стоит ли начинать с бесплатного LibreDWG или экономика склоняется к ODA.

## Почему отдельно от продукта

LibreDWG распространяется под **GPL-3**. Здесь он используется как локальный
инструмент разработчика, поэтому пакет вынесен за пределы рабочих пакетов
(`workspaces: packages/*`) — он не попадает ни в бандл фронтенда, ни в
Docker-образ, и не влияет на лицензию продукта.
